# Imagem Canônica de Referência — Nox v1

## Papel Canônico

- O operador fornecerá o arquivo `nox_v1_reference.png` neste diretório.
- Nenhuma pose futura deve alterar o rosto, cabelo, roupas-base, proporções ou idade aparente definidos nesta imagem.
